# Website
This is for my website

## Files
- `index.html` — all content and script. Each chapter has a comment banner, for example `CHAPTER V — THE TRACK RECORD`. Search for it to find a chapter.
- `style.css` — all styling.
- `images/` — photos. Journal photos are in `images/gallery/`, Wisdom photos in `images/wisdom/`.
- `assets/` — CV PDF. Replace `Md_Rabbinzzaman_CV.pdf` to update the CV.

## Common updates
- **New job or study entry:** copy one `<li>` in the `record-list` of chapter V and change the text.
- **New Wisdom post:** copy one `<article class="wisdom-post">` block in chapter VII.
- **New Journal photo:** add the file to `images/gallery/`, then add one line to the `galleryImages` list in the script at the bottom of `index.html`.
